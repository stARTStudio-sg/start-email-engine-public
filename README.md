# stART Studio Email Engine — Public Demo

An interactive, browser-based edition of the stART Studio content workflow.

The public demo includes topic selection, angles, hooks, email structures,
writing styles, editable drafts, visual previews, social repurposing and video
scripts. It uses sample research and local generation logic; it does not expose
private credentials or perform live AI research.
